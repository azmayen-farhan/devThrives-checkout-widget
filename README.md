# DevThrives Checkout Widget

Two Elementor widgets for WooCommerce: a one-page checkout and an advanced thank-you page order summary.

## Features
- One-page checkout: product selection, customer form, shipping, payment and order button in one widget
- Choose products manually, by query (category, tag and similar), the current product, or from the cart
- Variation selector on product cards, quantity and coupon support
- Shipping and payment methods come from your WooCommerce settings
- Live totals: the order summary updates through AJAX without a page reload
- Show or hide each field and mark it required or optional
- Edit every heading, label and message from the Elementor panel
- Send customers to a thank-you page of your choice after the order
- Order summary widget for the thank-you page
- Compatible with WooCommerce High-Performance Order Storage (HPOS)

## Requirements
- WordPress 6.0+
- PHP 7.4+
- WooCommerce and Elementor

## Installation
1. Download the plugin zip from the Releases page.
2. Go to Plugins > Add New > Upload Plugin and upload it.
3. Activate it, then search for the checkout widget in Elementor and drag it into a page.
